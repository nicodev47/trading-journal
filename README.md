# EclipseJournal - React/Vite

Versione standalone pulita del journal, convertita da Next/v0 a React + Vite.

## Sviluppo locale

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`

Non servono `.nvmrc`, Next.js, Vercel o cartelle `.v0`.
